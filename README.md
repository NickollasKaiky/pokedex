# Pokédex

Aplicação web em que você digita o nome de um Pokémon e vê uma carta com as informações dele. Os dados vêm da <a href='https://pokeapi.co/'>PokéAPI</a>.

Projeto feito em dupla, usando só HTML, CSS e JavaScript.
